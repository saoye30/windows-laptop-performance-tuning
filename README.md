# Windows 笔记本电源与性能调优

让 AI 助手帮你检查笔记本的电源设置，理解性能与续航之间的取舍，再按你的选择进行调整。

本项目是一套面向普通用户的 **AI 助手技能（Skill）**，包含操作说明、检查脚本和电源配置包。你可以用日常语言描述需求，由支持本地技能和 PowerShell 的 AI 助手协助完成：**先检查 → 解释方案 → 你确认 → 备份与调整 → 重启验证**。

> 适用于 Windows 11 笔记本，以及满足硬件条件的 Windows 平板。实际效果取决于处理器、机型、散热和厂商软件，不保证提升游戏帧率或延长多少续航。

## 能帮你做什么

| 你的需求 | 技能提供的帮助 |
| --- | --- |
| 不清楚电脑适不适合调整 | 检查系统、处理器、电源方案、已安装的配置包，以及可能冲突的厂商软件 |
| 想调整插电性能与电池续航的取舍 | 为匹配的处理器安装 Tongfang 通用 PPKG 1.44，调整不同使用场景下的处理器电源策略 |
| 想查看 Windows 隐藏的电源设置 | 安装 Power Settings Explorer，并显示处理器的隐藏电源选项 |
| 想了解显卡、搜索、浏览器或 Steam 的设置影响 | 说明现有调优选项的改动与副作用，按确认的范围执行 |
| 想更换华硕或联想的控制软件 | 协助检查适配情况，提供 G-Helper 或 Lenovo Legion Toolkit 的替换流程 |
| 调整后想恢复 | 利用备份和撤销脚本恢复相关配置，并在重启后检查结果 |

**PPKG 是什么？** 可以把它理解为 Windows 的一份配置包。本项目附带的包用于调整处理器电源策略，例如插电游戏时更积极地保持性能、使用电池时更偏向节能。它不刷 BIOS，也不进行超频。

## 开始使用

### 1. 下载完整项目

在本仓库页面点击 **Code → Download ZIP**，解压到一个方便长期保留的位置。会使用 Git 的用户也可以运行：

```powershell
git clone https://github.com/saoye30/windows-laptop-performance-tuning.git
```

请保留完整目录，不要只下载单个脚本。后续撤销可能需要调用原目录中的脚本，因此安装后也不要随意移动或删除它。

### 2. 让 AI 助手加载技能

按照你所用 AI 工具的说明，将项目放入它支持的本地技能目录，或让它读取本项目的 [技能说明](<SKILL.md>)。技能标识为 `windows-laptop-performance-tuning`；不同工具的导入方法可能不同。

助手需要能读取项目文件，并在**你要调整的那台 Windows 电脑**上运行 PowerShell。只有网页聊天、无法访问本机的助手，可以解释方案，但不能替你完成本机安装。

### 3. 告诉助手你的目标

可以直接复制下面这段话开始：

> 请使用 windows-laptop-performance-tuning 技能，先检查我的电脑是否适合调整。用普通话解释结果，只做检查，不修改系统。之后列出建议、可能的副作用和恢复方法，等我确认再执行。

也可以提出更具体的要求：

- “我主要插电玩游戏，先帮我看看电源设置是否合适。”
- “我更在意续航，请解释哪些调整可能适合我，哪些反而会更耗电。”
- “我只想检查 PPKG 适配，不要改 Windows 更新、搜索、浏览器和 Steam。”
- “帮我判断这台华硕笔记本能不能用 G-Helper，先不要卸载任何软件。”
- “我想撤销上次调整，请先找到备份，再说明恢复步骤。”

### 4. 确认方案后再调整

助手应先说明要改哪些设置、可能有什么代价，以及如何撤销。正式安装需要管理员权限，完成后需要重启并验证。

**脚本本身不会逐项弹出确认框。** 确认应在助手执行命令之前完成；自己手动运行时，也要先看清参数和改动范围。

## 哪些电脑适合使用

- **系统：** Windows 11；不支持 Windows 10。
- **设备：** 以笔记本为主，兼容条件中的部分 Windows 平板也可检查；不面向台式机或工作站安装该预配包。
- **处理器：** 需要按实际硬件信息匹配。部分 Intel 第 13/14 代移动处理器、Core Ultra，以及部分 AMD Ryzen 7000/8000、Ryzen AI 等在目标表中，但同一系列并非所有型号都适用。
- **已有配置：** 如果装过其他厂商的预配包，应先检查冲突，不能直接叠加安装或随意删除原包。
- **厂商软件：** 奥创、Vantage、Legion Zone 等软件可能重新写入电源设置，覆盖调整效果。

具体型号见 [处理器适配表](<references/supported-cpus.md>)，最终以扫描结果为准。“仅兼容”不等于一定有收益，“原生支持”也不代表厂商对你的整机作出适配承诺。

## 调整前需要了解的取舍

当前安装脚本默认除了安装电源配置包，还会准备电源设置工具，并尝试执行 NVIDIA、Windows 搜索、Windows 更新、浏览器和 Steam 的配套调整。缺少相应软件或不满足执行条件的项目可能跳过。

**这些选项不是所有人都应该启用的通用优化。** 如果你只想调整处理器电源策略，可让助手使用 `-SkipTune` 跳过全部系统性能项；也可以用 `-TuneOnly` 选择需要的类别。

| 调整项 | 当前脚本的行为 | 你需要考虑的影响 |
| --- | --- | --- |
| NVIDIA 电源与缓存 | 全局电源管理设为最高性能优先，关闭着色器缓存 | 功耗、发热可能增加；缓存关闭后，部分游戏可能增加编译等待或出现卡顿 |
| Windows 搜索 | 停用搜索索引，关闭部分网页搜索建议 | 文件内容搜索可能变慢 |
| Windows 更新 | 将更新暂停时间设为 2099-12-31 | 安全补丁也会暂停；日常使用建议保留更新，不选择此项 |
| 浏览器 | 对检测到的支持浏览器关闭硬件加速、调整后台运行和自启动等设置 | 视频播放和网页渲染可能增加 CPU 占用与耗电；可能显示“由你的组织管理” |
| Steam | 关闭网页 GPU 加速、硬件视频解码和着色器预缓存 | 界面、视频和部分游戏的体验可能受影响；Steam 正在运行时默认跳过，除非允许脚本将其正常退出 |
| 隐藏电源选项 | 下载固定版本 Power Settings Explorer，校验文件后显示处理器隐藏项 | 该工具没有数字签名，Windows 可能提示；显示选项本身不会改变电源数值 |
| 厂商控制软件替换 | 按机型协助从华硕奥创转向 G-Helper，或从联想相关软件转向 Lenovo Legion Toolkit | 部分官方功能可能失去，需要保留必要驱动；恢复官方软件要单独处理 |

`-TuneOnly` 当前按类别选择，例如选择 `Nvidia` 会同时包含 NVIDIA 电源和缓存两类设置，不能把它理解为只改一个开关。具体执行范围应以预演结果和脚本为准。

## 想自己检查？先运行只读扫描

在解压后的项目根目录打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\scan_power.ps1"
```

这一步只读取本机信息，不修改电源设置。部分信息（例如已安装预配包）需要管理员权限才能完整读取；读取失败不代表没有安装。

下面的命令预演“只安装电源配置包”的流程，跳过电源工具和系统性能项：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\install_ppkg.ps1" -DryRun -SkipPse -SkipTune
```

`-DryRun` 不执行安装，但仍需读取本机信息，可能因权限不足或适配检查未通过而停止。不要为了跳过检查而直接去掉这个参数。

常用参数如下，供你与助手核对方案：

| 参数 | 含义 |
| --- | --- |
| `-DryRun` | 预演检查与操作计划，不实际安装 |
| `-SkipTune` | 跳过 NVIDIA、搜索、更新、浏览器和 Steam 的系统性能项 |
| `-SkipPse` | 跳过 Power Settings Explorer 安装和隐藏电源项显示 |
| `-TuneOnly "Nvidia,Steam"` | 仅选择指定的系统性能类别；可用类别为 `Nvidia`、`Search`、`Update`、`Browser`、`Steam` |
| `-CloseSteam` | 允许脚本正常退出 Steam 后调整配置；运行前先保存游戏进度 |

正式安装请在完成适配检查、核验配置包并确认方案后进行。详细流程见 [技能说明](<SKILL.md>)。

## 如何恢复原来的设置

正式安装会在桌面创建名称类似 `PowerPPKG_Backup_日期-时间` 的备份目录，保存电源配置、相关记录和生成的撤销脚本。脚本还会尝试创建系统还原点，但是否成功取决于系统保护设置等条件。

1. 保留备份目录和原项目目录，告诉助手你想撤销哪次调整。
2. 让助手检查备份与日志，说明会恢复的内容，再以管理员权限执行撤销。
3. 重启电脑，核对预配包状态和电源设置；浏览器、Steam 与 NVIDIA 的相关设置也需要分别确认。

恢复流程会使用备份卸载本项目的预配包、写回电源配置，并根据记录恢复相关系统性能项和电源选项显示状态。**撤销命令执行结束不等于所有设置都已恢复成功**，应检查日志和实际状态。

厂商控制软件替换有独立的备份和恢复流程，不会由电源配置包的撤销流程自动装回。只读扫描或安装早期失败时，也不一定已经生成完整备份和撤销脚本，应先查看日志。

## 常见问题

### 下载后双击就能优化吗？

本项目提供的是 AI 技能与脚本，没有独立的“一键优化”界面。建议先让助手检查和解释，再选择需要的调整。

### 能保证游戏更流畅或续航更长吗？

不能。更积极的性能策略可能增加发热和耗电，节能策略也可能降低性能。建议在相同电源模式、游戏场景和环境下做前后对比；体验变差就检查原因或撤销。

### 必须卸载奥创或联想管家吗？

不必须。只有在机型适配、你了解替代软件的功能差异并明确同意时才考虑替换。华硕奥创使用官方卸载工具；联想相关软件优先考虑在替代工具中禁用，保留恢复途径。不要卸载控制软件依赖的驱动。

### 会清理文件、刷 BIOS 或关闭杀毒软件吗？

这些不在本技能的范围内。它不负责磁盘清理、驱动更新、超频、刷 BIOS，也不通过关闭 Defender 或内存完整性来提升性能。

### 遇到问题怎么反馈？

可以在 [Issues](https://github.com/saoye30/windows-laptop-performance-tuning/issues) 中描述 Windows 版本、电脑型号、CPU、选择的调整项，以及报错信息。提交日志前请检查并隐藏用户名、本地个人路径等隐私信息，不要上传整个系统备份目录。
